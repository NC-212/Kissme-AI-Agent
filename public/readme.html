行銷自動化工作流

整合多代理人協作、生成式 AI 與化妝品廣告法規庫，打造台灣品牌專屬的內容生成引擎。

01

第一階段：系統與基礎資料設定

輸入資料

讓 AI 認識你的品牌、產品與受眾，以便後續產出精準的內容。

API 初始設定

進入系統設定，前往 Google AI Studio 申請並貼上 Gemini API Key，作為啟動核心引擎的金鑰。

新增產品資料

在「產品管理」建立推廣商品，輸入基礎的「產品名稱」與「產品特色」。

設定目標受眾 (TA)

在「TA 設定」新增客群輪廓，包含 TA 標籤、描述以及最重要的核心「痛點」。

擴充詳細量化資訊

選擇產品並輸入成分、持妝時間或實測數據等深入資料，增強文案說服力。

產品圖像預期風格

幫助定義視覺走向，輸入風格名稱與描述（含關鍵字、光線與構圖要求）。

建立專屬文案風格

貼上過去優質文案，由 AI 分析寫作慣性並產出專屬 Prompt 與 JSON 格式。

02

第二階段：核心行銷內容生成

生成結果

多代理人協作 (Multi-Agent)，產出多媒體渠道素材。

文案生成與內容審查

選擇生成模式（「TA & 痛點導向」或「產品介紹導向」）。系統內建「AI 審查官」機制：AI 先產出初稿，交由審查代理人進行批評建議與法規修正，最終才生成高品質文案。

預覽與再編輯文案

檢視包含標題、解方、特點與促購之區塊，確認後可儲存至文案存摺或複製。

法規合規校閱

同步進行化妝品廣告法規自動過濾，確保無醫療效能宣稱等違規詞彙。

社群圖像 Prompt 生成

輸入社群文案與圖像風格，產出構圖理念與全英文 AI 指令 (Prompt)，可直接運用於外部生圖服務（如 Midjourney）。

短影音 (Reels) 腳本

自動將貼文轉化為 9:16 影音腳本格式，清晰劃分「旁白 (Voiceover)」與「畫面元素 (Visual)」，作為拍攝參考。
